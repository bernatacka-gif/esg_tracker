# EcoPulse Project History

## Project Overview
**EcoPulse — European Fashion ESG Tracker** is a premium, single-file corporate dashboard designed for tracking and visualizing ESG (Environmental, Social, and Governance) performance across major stock indices.

## Development Timeline & Features

### Phase 1: Foundation
- Developed a high-end corporate dashboard using a dark forest green and crisp white palette.
- Created a single-file architecture (`index.html`) using HTML5, CSS3, and JavaScript.
- Integrated **Chart.js** via CDN for data visualization.
- Implemented a live-filtering data table with five fictional European fashion brands.

### Phase 2: Multi-Index Expansion
- Upgraded the dataset to include the **STOXX 600 Leaders** and **S&P 500 Giants** (20 companies total).
- Added a sleek tab-based navigation system to swap between datasets instantly.
- Introduced advanced ESG metrics: **MSCI ESG Ratings** and **Sustainalytics Risk Scores**.
- Implemented a "Global Peer Average" benchmark card.

### Phase 3: Interactive Trading Profiles
- Restructured the dashboard to support clickable rows.
- Built a sophisticated modal window mimicking a professional financial terminal.
- Displayed real-time trading data (Ticker, Price, % Change, Market Cap, P/E Ratio).
- Populated unique, realistic business summaries for every company.

### Phase 4: Deep Dive ESG Analytics
- Enhanced the modal with a specialized **"Deep Dive ESG Analytics"** section.
- Added company-specific data including:
    - **Controversy Radar:** Risk-level badges (Low/Medium/High) with compliance notes.
    - **EU Taxonomy Alignment %**.
    - **Net Zero Strategic Roadmap** (Target year and status).
    - **PAI Metrics:** Hazardous Waste Ratio and Gender Pay Gap.
    - **Primary ESG Challenge** identification.

### Phase 5: Executive Visualization Layer
- **KPI Summary Cards:** Added top-level metrics for MSCI Performers, Emissions, and Risk Profiles.
- **Sparklines:** Integrated animated miniature line charts inside KPI cards to visualize simulated positive trends.
- **Radar Analysis:** Embedded a multi-dimensional Chart.js Radar Chart in the modal for a visual 5-point ESG analysis (Environmental, Social, Governance, Carbon Efficiency, and Taxonomy Alignment).

### Phase 6: Asset Finalization
- Configured the system to support custom branding via `image.png`.
- Finalized horizontal banner styling with `object-fit: cover` for a polished, responsive look.
